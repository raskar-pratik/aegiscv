# Veyra analyst workstation

The running offline Flask interface is the design authority. Primary users: security assurance analysts, ML security engineers, defence and critical-infrastructure evaluators, and technical decision-makers. Mode: Operate. Preserve every detector, threshold, metric, cryptographic control and decision contract. Evaluation provenance is documented separately from the product identity.

## Direction
Decision first, evidence second, technical disclosure third. Medium-high density, moderate layout variance and low motion. Use a compact grouped navy rail, readable white investigation surfaces and explicit status language. Never infer verification from the presence of a signature. Risk is risk, not an inverted health score. Experimental evidence requires review; attribution does not establish causation.

## Components and behavior
Tables: distinct slate headers, left-aligned names, right-aligned numbers, restrained row separators, hover and focus, expandable evidence. Contain horizontal overflow within the table at narrow widths.
Charts: meaningful reference/current comparisons, labeled values, consistent units, no invented measurements or decorative gauges. Render actual trigger/mask arrays only when supplied.
Status: verified requires successful backend verification; failed names the actual failure; unknown is neutral; review is amber; quarantine/reject is red. Reliability and execution status remain separate. Unavailable is never a pass.
Hash values: abbreviated prefix/suffix, full value in disclosure, copy control with feedback.
Forms: visible labels, pending/disabled states, useful errors, retained input. Technical JSON collapsed. Navigation supports keyboard focus and browser history. Reduced motion disables transitions.
Responsive: primary 1440x1000; verify 1366x768 and 1920x1080. At 1366 the title, disposition, reason, metrics and evidence entry point fit above fold. Below 900 collapse multi-column investigations; below 720 use a horizontal navigation region. No page-wide overflow.
